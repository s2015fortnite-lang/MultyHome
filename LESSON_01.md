# Шаг 1. Как сообщение превращается в действие

Представьте, что вы пишете боту `/on 1`.

1. Telegram сохраняет ваше сообщение.
2. `bot.py` запрашивает новые сообщения через `getUpdates`.
3. Программа получает ваш Telegram ID — числовой номер аккаунта.
4. `accounts.py` находит токен вашего Яндекса по этому ID.
5. `bot.py` находит устройство №1 в вашем последнем списке `/devices`.
6. `yandex_home.py` отправляет Яндексу команду включения с ID устройства.
7. Яндекс проверяет доступ, передаёт команду и возвращает результат.
8. Бот отвечает вам через `sendMessage`.

Telegram ID и ID устройства — разные вещи. Первый определяет человека,
второй — конкретную лампу, розетку или другое устройство.
Номер `1` — временная позиция устройства в списке, а не его настоящий ID.

## Какие данные нужны

**Токен Telegram-бота** разрешает нашей программе работать от имени бота.
Его выдаёт BotFather.

**Client ID** — номер нашего приложения у Яндекса. Это не пароль.

**Client secret** — секрет нашего приложения. Он нужен программе при обмене
одноразового кода на токен. Пользователи его не получают.

**Код авторизации** — одноразовый код, который Яндекс выдаёт пользователю после
его согласия. Бот отправляет код Яндексу и получает токен доступа этого пользователя.

**Токен Яндекса** разрешает программе обращаться к дому конкретного пользователя.
У разных пользователей разные токены. Client ID и Client secret сами по себе
не дают доступ к чьим-либо устройствам.

## Самые простые элементы Python в этом проекте

`text = "/on 1"` — сохраняет строку в переменную с именем `text`.

`parts = text.split()` — делит строку по пробелам. Получится список
`["/on", "1"]`. `parts[0]` — первый элемент, `parts[1]` — второй.

`if command == "/on":` — проверяет условие. Строки с отступом под ним
выполняются, если условие верно.

`for device in devices:` — перебирает устройства по одному.

`def handle(self, text):` — объявляет функцию внутри класса.
Функция выполняет небольшой участок работы. Класс здесь просто объединяет
данные и функции: например, `Commands` хранит список устройств и разбирает команды.
`self.devices` означает «список устройств этого экземпляра». У разных
пользователей разные экземпляры, поэтому списки не смешиваются.

`return` — возвращает результат из функции.

`try` / `except` — позволяет обработать ожидаемую ошибку, например отсутствие сети,
и показать понятное сообщение вместо завершения программы.

## Ваша первая проверка

Запустите `bot.py --demo-console` по инструкции в README.
Введите `/devices`, `/on 1`, `/status 1`.
Программа должна показать, что учебная лампа включена.
Затем выполните `/off 1` и `/status 1`: состояние должно измениться.

После этого попробуйте `/on 99`. Программа должна сообщить, что такого номера нет.
Так мы проверяем и обычное действие, и ошибку ввода.

Учебный режим изменяет только данные в памяти Python. После перезапуска
виртуальные устройства снова выключены. Ни запросов к Яндексу, ни управления
настоящим домом в этой проверке нет.
