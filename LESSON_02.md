# Шаг 2. Настройки устройства: яркость, цвет, температура, режимы

Название устройства ничего не говорит о его командах. Лампу можно назвать
«Кондиционер», но от этого она не научится охлаждать воздух.
Поэтому программа читает список `capabilities` — возможностей, которые Яндекс
возвращает для конкретного устройства.

## Что мы читаем

Пример части ответа Яндекса:

```json
{
  "type": "devices.capabilities.range",
  "parameters": {
    "instance": "brightness",
    "range": {"min": 1, "max": 100, "precision": 1}
  },
  "state": {"instance": "brightness", "value": 50}
}
```

- `type` означает вид возможности. `range` — настройка числом.
- `parameters.instance` говорит, что именно меняется: здесь яркость, `brightness`.
- `min` и `max` задают допустимые границы.
- `precision` задаёт шаг изменения. Например, при шаге `0.5` можно задать `22.5`.
- `state.value` — текущее значение, если Яндекс его передал.

`state` может быть `null`. Это не запрещает управление: возможность может
принимать команды, даже если прочитать её текущее значение нельзя.
Для выбора команды мы читаем `parameters`, а не угадываем её по состоянию.

## Как работает /brightness 1 70

1. `bot.py` делит сообщение по пробелам: команда, номер устройства, значение.
2. В личном списке пользователя находит устройство №1 и его ID.
3. `yandex_home.py` получает свежие сведения об этом устройстве.
4. `capabilities.py` ищет `range` с `instance=brightness`.
5. Проверяет, что `70` входит в диапазон и соответствует шагу.
6. `yandex_home.py` отправляет одну команду устройству с этим ID:

```json
{
  "type": "devices.capabilities.range",
  "state": {"instance": "brightness", "value": 70, "relative": false}
}
```

`relative: false` означает «установить 70», а не «прибавить 70».
Если устройство разрешает только относительные изменения, бот пока не отправляет
ему абсолютную команду. Это ограничение явно показывается в `/capabilities`.

Яндекс отвечает результатом команды. Бот проверяет, что подтверждение относится
к нужному устройству, нужному виду возможности и нужной настройке, а результат
равен `DONE`. После этого показывает «команда выполнена».

## Разные виды возможностей

| Возможность | Что делает | Команда-пример |
| --- | --- | --- |
| `on_off` | Включение/выключение | `/on 1` |
| `range`, `brightness` | Яркость числом | `/brightness 1 70` |
| `range`, `temperature` | Заданная температура устройства | `/temperature 3 22.5` |
| `range`, `volume` | Громкость | `/volume 4 30` |
| `mode`, `thermostat` | Выбор режима из объявленного списка | `/mode 3 thermostat cool` |
| `color_setting`, `rgb` или `hsv` | Цвет | `/color 1 FF0000` |
| `color_setting`, `temperature_k` | Температура белого света | `/white 1 4000` |
| `color_setting`, `scene` | Сцена освещения | `/scene 1 reading` |

Числа в таблице относятся к нашему учебному дому.
В настоящем доме номера и возможности могут отличаться.
Единицы температуры и громкости берутся из параметров устройства.

## Что означает цвет FF0000

HEX — запись числа цифрами `0–9` и буквами `A–F`. Цвет записывается шестью
символами: первые два — красный, следующие два — зелёный, последние два — синий.
`FF0000` — красный, `00FF00` — зелёный, `0000FF` — синий.

Яндекс принимает RGB как одно число, поэтому Python переводит запись в число
через `int(text, 16)`. Например, `FF0000` превращается в `16711680`.
Если устройство объявляет модель HSV, программа пересчитывает цвет в тон,
насыщенность и яркость встроенной функцией Python `colorsys.rgb_to_hsv`.
Отправляемая яркость HSV может менять яркость цвета; это часть формата HSV.

## Как проверить на ваших Станциях

1. Обновите проект и перезапустите бота по README.
2. В Telegram отправьте `/devices`.
3. Отправьте `/capabilities 1`.
4. Если в ответе есть `/volume 1 ЗНАЧЕНИЕ`, выберите небольшую комфортную
   громкость в указанном диапазоне и отправьте команду.
5. Если Яндекс не объявил настройку громкости, бот её не предложит. Наличие
   колонки само по себе не гарантирует доступность управления через этот API.

Для проверки цвета нужна лампа, которая объявляет изменение цвета.
Но проверить код можно уже сейчас на виртуальной лампе через `--demo-console`.

## Два упражнения

В учебном режиме отправьте `/brightness 1 150`. Бот должен отклонить команду,
поскольку максимум виртуальной лампы равен 100. Затем отправьте допустимое значение.

Отправьте `/mode 3 thermostat madeup`. Бот должен показать допустимые режимы.
Затем выберите один из списка. Так вы проверите не только правильное действие,
но и обработку ошибочного ввода.

В `capabilities.py` найдите функцию `find_capability`. Она перебирает список
и сравнивает `type` и `instance`. Это основной принцип работы новых команд.
