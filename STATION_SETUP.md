# Отдельное подключение Яндекс Станции на Mac

Это первый этап **неофициальной** интеграции со Станцией: чтение конфигурации,
включение/выключение эквалайзера и изменение пяти полос. Форматы методов сверены
с открытой интеграцией AlexxIT/YandexStation, а не с публичной документацией Яндекса.
Код проверен тестами и на виртуальной Станции. Настоящий сервер и ваше устройство
нужно проверить после подключения; их работоспособность пока не подтверждена.

Музыкальный плеер, «Не беспокоить», стереопара, звонки и остальные внутренние
настройки пока не управляются. Известные поля состояния доступны через `/status`.
Для следующего этапа есть `/station_info`: он показывает структуру конфигурации
без значений. Не предполагаем, что прочитанное состояние совпадает с форматом
команды изменения.

## Почему нужно ещё одно подключение

В проекте теперь два подключения:

- Яндекс Дом — OAuth-токен из `/connect`, для официального API устройств;
- Станция — браузерная сессия для отдельного API конфигурации.

Cookie — секрет браузерной сессии. Он может предоставлять доступ к аккаунту
Яндекса, поэтому его вводим только в локальную программу через скрытый ввод.
Не отправляйте Cookie в Telegram, сюда в чат или на GitHub. Не вставляйте его
в саму команду терминала: так он попадёт в историю команд.

У каждого Telegram-пользователя отдельная запись. Скрипт сравнивает ID устройств
из OAuth-подключения пользователя с ID из браузерной сессии и привязывает только
совпавшие Станции с объявленным эквалайзером. Это проверка доступа к одним и тем же
устройствам, а не сравнение названий или доказательство совпадения личности.

В этом учебном варианте привязка делается локально владельцем компьютера.
Самостоятельная авторизация произвольных пользователей через веб-интерфейс пока
не реализована.

## 1. Обновить проект

Остановите бота через `Ctrl+C`. В терминале, в папке `MultyHome`:

```bash
git pull --ff-only
```

Если Git сообщает о ваших изменённых файлах, сначала сохраните их. Не удаляйте
изменения для обхода сообщения Git. Новые библиотеки не нужны.

## 2. Узнать свой Telegram ID

Запустите бота:

```bash
.venv/bin/python bot.py
```

В личном чате отправьте `/id`. Сохраните полученный числовой ID.
Для настоящего дома в `.env` должно быть `DEMO_MODE=0`; дом должен быть уже
подключён через `/connect` и `/code`. Проверьте `/devices`.
После этого остановите бота через `Ctrl+C`.

## 3. Получить Cookie локально в Chrome

1. На своём Mac откройте Chrome и войдите в **свой** Яндекс-аккаунт со Станцией.
2. Откройте `https://yandex.ru/quasar`.
3. Нажмите `⌘ + ⌥ + I` (Command + Option + I), чтобы открыть инструменты разработчика.
4. Перейдите на вкладку **Network** (Сеть) и обновите страницу через `⌘ + R`.
5. В списке найдите запрос страницы `quasar` к `yandex.ru` и нажмите на него.
6. Справа откройте **Headers** → **Request Headers** → **Cookie**.
7. Скопируйте только значение Cookie — строку вида `имя=значение; имя=значение`.

Нужны именно **Request Headers**, а не ответ сервера `Set-Cookie`.
Если Chrome показывает список cookies отдельно, смотрите заголовки запроса
через **view source**. Не копируйте весь запрос через «Copy as cURL»:
он содержит секреты и лишние данные.

Если страница или запрос теперь имеют другой адрес и `quasar` не находится,
не подставляйте произвольный Cookie. Неофициальный сайт мог измениться: сообщите
адрес страницы или текст ошибки без секретных заголовков.

## 4. Привязать сессию к себе

В терминале выполните, заменив число на свой Telegram ID:

```bash
.venv/bin/python station_login.py --user-id 123456789
```

Программа попросит `Cookie (ввод скрыт):`. Вставьте скопированное значение и
нажмите Enter. Пока вставляете, символы не отображаются — это нормально.
После ввода очистите буфер обмена, например скопировав обычный текст.

Скрипт проверяет доступ к списку устройств, чтение конфигурации и получение
CSRF-токена. Он **не меняет** эквалайзер при подключении. Если проверки прошли,
сохраняется файл `station_sessions.json`, и программа сообщает число привязанных
Станций. На Mac файл создаётся с правами только для владельца процесса.

`station_sessions.json` содержит секреты и исключён из Git, как `.env` и `users.json`.
Не публикуйте эти файлы и не включайте их в общедоступные архивы или облачные снимки.

## 5. Проверить эквалайзер

Снова запустите бота:

```bash
.venv/bin/python bot.py
```

В Telegram отправьте `/devices`, затем `/station НОМЕР_СВОЕЙ_КОЛОНКИ`.
Бот должен показать состояние эквалайзера и усиления полос.
Далее можно отправить:

```text
/equalizer 2 on
/eqbands 2 -3 0 0 0 3
/station 2
```

Вместо `2` используйте фактический номер Станции. `on` включает эквалайзер,
`off` выключает. `/eqbands` включает эквалайзер, выбирает пользовательскую
настройку и устанавливает пять усилений от низких частот к высоким.
В этой версии бот разрешает только целые значения от -6 до +6 дБ — это
ограничение программы, а не утверждение о полном диапазоне устройства.
Частоты и ширины существующих полос сохраняются.

Не проверяйте изменение на большой громкости. Сначала запишите текущие значения
и проверьте результат также в приложении «Дом с Алисой». Ответ «Яндекс принял»
означает `status=ok` от сервера, а не измерение фактического звучания.

Если API не вернул секцию эквалайзера, откройте настройку эквалайзера Станции
в приложении Яндекса и повторите чтение. Бот не создаёт неизвестную конфигурацию.
Если сервер по-прежнему не даёт секцию, пришлите текст ошибки и ответ
`/station_info НОМЕР`; не отправляйте сам файл с сессиями.

## 6. Подготовить следующие настройки

После успешного подключения отправьте:

```text
/station_info 2
```

Команда читает конфигурацию, скрывает все значения и показывает поля. Этот ответ
можно передать для разработки следующих функций. Он не запускает музыку,
не включает звонки и не меняет настройки.

При истечении сессии повторите `station_login.py` и перезапустите бота.
`/disconnect` удаляет и OAuth-подключение, и локальную запись сессии этого пользователя.
Сам браузерный сеанс Яндекса при этом не отзывается: завершить сеансы можно
в настройках безопасности Яндекс ID.

Для облачного запуска дополнительно нужен HTTPS-доступ к `iot.quasar.yandex.ru`
и `yandex.ru`. Сейчас подключение описано для локального Mac. Доступ из облака
к этим методам с действующей сессией не проверен.

## Проверка без авторизации

```bash
.venv/bin/python bot.py --demo-console
```

В учебном доме Станция имеет номер 5:

```text
/devices
/capabilities 5
/station 5
/equalizer 5 on
/eqbands 5 -3 0 0 0 3
/station 5
/status 5
exit
```

Эта проверка не обращается к Яндексу. Учебные настройки исчезают при перезапуске.
